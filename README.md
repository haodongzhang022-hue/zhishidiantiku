## 目录结构
| 路径 | 说明 |
|------|------|
| questions/ | 题目库，按知识点一级目录分类，每题一个 .md 文件 |
| questions/README.md | 题目收录规范（格式要求） |
| scripts/check.mjs | 题目格式校验脚本（CI 门禁） |
| docs/ | 使用与扩展文档（待建） |

## 题目格式（速览）
```md
# 题目：<一句话题干>
- 难度：简单 | 中等 | 困难
- 分类：<一级分类，如 开发基础>
- 题型：单选 | 多选 | 判断 | 简答

## 题目
<题干正文>

## 选项
A. ...
B. ...   （简答题可省略）

## 答案
<正确答案或答题要点>

## 解析
<为什么对 / 为什么错>
```

## 贡献方式
1. 新建分支，题目文件放入 questions/ 对应分类目录；
2. 本地运行 `node scripts/check.mjs` 校验通过后提交；
3. 提 PR，CNB 流水线自动跑同一校验，绿灯后可合并。
