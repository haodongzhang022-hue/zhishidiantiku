# 个人学习进度系统（做题 · 出题 · 进度库）

> 让"知识点题库"真正能用来练、能查个人进度。把题库变成你自己的"会/不会"进度库。
> 入口脚本：`node scripts/learn.mjs`（Node ≥18，无第三方依赖）。

## 它解决什么

- 显示你**当前会做哪些知识点、哪些还不会**（会/学习中/未学 三态区分）。
- 判断"会了"：在**同一个知识点**随机抽 **2 道不同（不连续）题**，都答对 = 该知识点「会了」；答错则清零重来。
- 随机出题 `quiz` **只从还没会的知识点**里抽，方便补弱。
- 进度以本地 JSON 持久化，形成个人进度库，方便检查与复盘。

## 快速上手

```bash
# 1. 看有哪些知识点、分别多少题
node scripts/learn.mjs list

# 2. 看自己当前个人进度（会/不会/未学）
node scripts/learn.mjs progress

# 3. 对某个知识点做"掌握测试"：随机抽 2 道不同题，全对即"会了"
node scripts/learn.mjs test "开发基础"

# 4. 随机刷题（只从还没会的知识点里出）
node scripts/learn.mjs quiz

# 5. 重置个人进度（可指定知识点，也可全部）
node scripts/learn.mjs reset "开发基础"
node scripts/learn.mjs reset
```

### 常用选项
| 选项 | 说明 |
|------|------|
| `--answer A,AC,y` | 非交互按出题顺序给答案（选择题给字母，简答用 `y` 表示自评答对）。需覆盖本次出题数：`test` 给 2 个、`quiz` 给 1 个；不足即报错退出，不静默顶替 |
| `--progress-file <path>` | 自定义进度库路径（默认 `~/.zhishidiantiku/progress.json`） |
| `--no-color` | 关闭彩色输出 |

## 三个关键规则

1. **知识点 = 题库目录**：`questions/<分类>/` 下的一级目录即一个知识点；
   有二级目录（如 `questions/AP化学/Unit1/`）时，按**二级单元**细分（`AP化学/Unit1`）。
2. **会了判定**：某知识点内连续答对 **2 道不同题** = 会；**答错会清零**，需重新积累（"都对了才叫会"）。
3. **随机只补弱**：`quiz` 只在**还没会**的知识点里出题；已会的不再出现。

> ⚠️ 判定"会了"需要某知识点 **≥2 道题**。题量不足的知识点无法判定，界面会提示先补题。

## 进度库结构

`progress.json`（个人数据，默认存用户主目录，不进 git）：

```json
{
  "version": 1,
  "points": {
    "开发基础": { "correct": ["DEV-BASE-MC-0001", "DEV-BASE-MC-0002"], "mastered": true, "updatedAt": "..." }
  }
}
```

## 判分口径

| 题型 | 判定 |
|------|------|
| 单选 / 多选 / 判断 | 与 `## 答案` 字母比对，自动判分（多选需子集完全一致） |
| 简答 | 展示参考答案，由你自评 `y/n` |

## 扩展

铺题时按知识点建目录，让每个知识点 ≥2 题，即可真正跑通"会了"判定。
题量越大，随机补弱越精准。详见 [题目收录规范](../questions/README.md)。
