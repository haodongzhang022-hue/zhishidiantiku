## 4 类题型在国内化学的落地口径
- 单选：对标中考选择题（"下列叙述正确的是"）。
- 多选 / 判断：适配多选题型与判断题，命题更稳。
- 简答：对标中考填空题/简答/实验探究小问，一题一个考点，附评分要点。
