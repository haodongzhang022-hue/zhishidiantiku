## 锚定依据（保证"题不歪"）
以 **IB Diploma Programme《Chemistry Guide》**（2023 发布、**2025 首考**）为唯一知识边界。
大纲正文：https://www.ibo.org/programmes/diploma-programme/curriculum/sciences/chemistry/

- 不超纲：题目考察点须落在下表"知识结构"内。
- IB 口径特点：**概念驱动（concept-based）+ 探究式（inquiry）**，重视原理理解、跨主题迁移与"结构与反应性"的关联；SL/HL 分层，HL 含额外拓展点。
- 题干尽量以 IB 式设问风格呈现（what/how/why + 数据/图谱情境），解析标注对应 Structure/Reactivity 主题。

## 4 类题型在 IB 化学的落地口径
- 单选 / 多选 / 判断：对标 IB Paper 1（选择题，A/B/C/D），只考 SL 或标注 HL。
- 简答：对标 IB Paper 2 结构化问答与计算，一题一个考察点，附评分要点。
- 与 AP/AL/国内 的口径差异：IB 更强调"用模型解释现象"与跨主题推理，而非纯识记/套公式。
