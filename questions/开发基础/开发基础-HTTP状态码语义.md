## 题目
当浏览器请求的资源不存在（服务端未找到）时，服务器通常返回哪个 HTTP 状态码？

## 选项
A. 200
B. 301
C. 404
D. 500

## 答案
C

## 解析
404 Not Found 表示请求的资源不存在，选 C。200 表示成功，301 表示永久重定向，500 表示服务器内部错误。掌握常用 HTTP 状态码语义是 Web 开发与排查接口问题的基础。源自开发基础通用知识（网络与 HTTP）。
