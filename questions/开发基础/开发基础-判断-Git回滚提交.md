## 题目
判断下列说法是否正确：使用 git revert 撤销某次提交时，会直接删除该提交及其历史记录。

## 选项
A. 正确
B. 错误

## 答案
B

## 解析
git revert 会**新建一个反向提交**来抵消指定提交的改动，原提交及其历史**保留**在版本库中（安全、适合已推送公共分支）。真正删除/改写历史的是 git reset --hard（本地）或变基改写历史，需谨慎。故题干"删除该提交及其历史"错误。理解 revert 与 reset 区别是 Git 工程化基础。源自开发基础通用知识（版本控制/Git）。
