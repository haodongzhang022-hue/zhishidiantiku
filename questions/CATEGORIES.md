# 分类与题型白名单登记

> 目的：给"分类"与"题型"建立**受控登记**而非拍死封锁。
> 原则：白名单 = **可查、可增、可回溯**。新增不设高门槛，但必须登记 **owner + 登记时间 + 更新历史**，让每次开放都留痕、可追责，避免目录悄悄失控、也避免谁想加都被挡住。

| 题型 | 英文 | 说明 | 选项要求 |
|------|------|------|----------|

### 维护机制（防止被挡也防止失序）
1. **加分类**：PR 追加表格行 + 更新历史，脚本白名单随合并自动放行新目录。
2. **加题型**：需评审拍板，4 类之外先不开放（需求驱动再扩）。
3. **改/删分类**：必须过 PR 并说明迁移路径，禁止静默清目录。
