# 题目收录规范

## 文件组织
- 每题一个 Markdown 文件，放 `questions/<分类>/` 下对应**一级白名单分类**目录。
- 分类必须在 `questions/CATEGORIES.md` 白名单内（owner + 登记时间留痕）。
- 文件名建议：`<分类>-<题目标题>.md`。

## 必填元信息（每题头部列表）
| 字段 | 说明 | 约束 |
|------|------|------|
| 题目ID | 全局唯一编号，可复制精准检索 | 必填，如 `AP-CHEM-CB-2024-MC-0001` |
| 难度 | 题目难度 | 简单 \| 中等 \| 困难（枚举） |
| 分类 | 一级白名单分类 | 须在 CATEGORIES.md 内 |
| 题型 | 题目类型 | 单选 \| 多选 \| 判断 \| 简答（**锁定 4 类**） |
| 范围 | 考察出处边界 | 指向 papers/ 登记表里的 scope_id（可选但强烈建议） |
| owner | 录入/负责人 | 必填 |
| 录入时间 | 入库日期 YYYY-MM-DD | 必填 |

## 必填小节
- 首行 H1 以 `# 题目：<一句话题干>` 开头。
- `## 题目` 题干正文。
- `## 答案` 正确答案或答题要点。
- `## 选项`：单选/多选/判断必填（A/B/C/D）；简答禁带。
- `## 解析`：建议补充（软校验）。

## 唯一编号机制
- 编号 = 可被**复制精准指向**某道题的唯一键（脚本强校验唯一）。
- 交流/检索/引用：直接粘贴编号即可定位。

## 提交门禁
- 本地 `node scripts/check.mjs` 全绿后再提交。
- 流水线 `.cnb.yml` 在 push/PR 自动跑同一校验，红灯阻塞合并。

## 归类与口径
- 一题只考一个知识点，不复合题干。
- 选择题/判断题必须补全 A/B/C/D，附解析。
- 术语用官方译名；来源可附解析末尾。
