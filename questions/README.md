# 题目收录规范

## 文件组织
- 每题一个 Markdown 文件，放 questions/ 下对应**一级分类**目录；分类用中文主题词（如 开发基础 / 数据结构与算法 / 网络与系统 / 数据库 / 前端 / 后端）。
- 文件名建议：`<主题>-<题目标题>.md`，如 `开发基础-什么是QPS.md`。

## 必填小节
| 小节 | 说明 |
|------|------|
| 首行 H1 | 以 `# 题目：<一句话题干>` 开头 |
| 元信息列表 | `- 难度 / 分类 / 题型` 三项 |
| ## 题目 | 题干正文 |
| ## 答案 | 正确答案或答题要点 |
| ## 选项 | 选择题必填（A/B/C/D）；简答题可省略 |
| ## 解析 | 建议补充，说明为什么对/为什么错 |

## 提交门禁
- 本地 `node scripts/check.mjs` 通过后再提交；
- CNB 流水线（.cnb.yml）在 push/PR 时自动执行同一校验，红灯则阻塞合并。

## 归类建议
- 判断题、选择题优先补全错误选项，附解析；
- 一道题只考一个知识点，避免复合题干；
- 术语使用官方译名，来源可另附在解析末尾。
