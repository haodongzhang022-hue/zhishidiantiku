## 题目
在500K时，反应 H2(g) + CO2(g) 可逆 CO(g) + H2O(g) 的Kc = 0.16。
若在2.0L容器中加入2.0mol H2 和2.0mol CO2，计算平衡时各物质的浓度。

## 答案
初始浓度：[H2]0 = [CO2]0 = 2.0/2.0 = 1.0 M
设x为反应掉的浓度：
平衡时：[H2] = [CO2] = 1.0 - x, [CO] = [H2O] = x
Kc = [CO][H2O]/([H2][CO2]) = x^2/(1.0-x)^2 = 0.16
取平方根：x/(1.0-x) = 0.4
解得 x = 0.4 - 0.4x，即 1.4x = 0.4，x = 0.286 M
平衡浓度：[H2] = [CO2] = 1.0-0.286 = 0.714 M, [CO] = [H2O] = 0.286 M

## 解析
这是经典的水煤气平衡问题。因为反应前后气体分子数相同（Δn=0），Kc = Kp。设未知数x并用ICE表求解。开方简化计算。源自AP Chemistry CED Unit 7平衡计算考点。
