## 题目
一个缓冲溶液由0.40M NH3 和0.30M NH4Cl 组成。已知NH3的Kb = 1.8x10^-5。
(a) 计算该缓冲溶液的pH。
(b) 如果向100mL该缓冲溶液中加入0.010mol HCl，计算新的pH。

## 答案
(a) pOH = pKb + log([NH4+]/[NH3]) = -log(1.8x10^-5) + log(0.30/0.40) = 4.74 + (-0.125) = 4.62
pH = 14 - 4.62 = 9.38

(b) 加入0.010mol HCl消耗NH3生成NH4+：
新的[NH3] = 0.40 - 0.010/0.100 = 0.30 M
新的[NH4+] = 0.30 + 0.010/0.100 = 0.40 M
pOH = 4.74 + log(0.40/0.30) = 4.74 + 0.125 = 4.86
新的pH = 14 - 4.86 = 9.14

## 解析
使用Henderson-Hasselbalch方程的碱性形式：pOH = pKb + log([共轭酸]/[碱])。加入HCl后需要计算浓度变化，注意加入的是0.010mol到100mL溶液中，浓度变化为0.010/0.100=0.100M。源自AP Chemistry CED Unit 8缓冲溶液计算考点。
