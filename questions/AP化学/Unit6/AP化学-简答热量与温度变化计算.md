## 题目
将200g水从20°C加热至80°C需要多少热量？水的比热容c=4.18 J/(g·°C)。如果使用500W的电热器加热，理论上需要多长时间？

## 答案
(1) q = mcΔT = 200 x 4.18 x (80-20) = 200 x 4.18 x 60 = 50160 J = 50.2 kJ
(2) 功率P=500W=500J/s，所需时间 t = 50160/500 = 100.3 s ≈ 1.67分钟

## 解析
使用 q=mcΔT 计算所需热量，然后使用 P=E/t 关系求时间。注意单位换算。源自AP Chemistry CED Unit 6比热容与热量计算考点。
