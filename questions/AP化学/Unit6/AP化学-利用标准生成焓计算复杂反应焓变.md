## 题目
利用标准生成焓计算反应 2Al(s) + Fe2O3(s) 到 Al2O3(s) + 2Fe(s) 的焓变。已知 ΔHf°(Al2O3) = -1676 kJ/mol, ΔHf°(Fe2O3) = -826 kJ/mol, ΔHf°(Al) = 0, ΔHf°(Fe) = 0。

## 选项
A. +850 kJ
B. -850 kJ
C. +2502 kJ
D. -2502 kJ

## 答案
B

## 解析
ΔHrxn = [ΔHf°(Al2O3) + 2xΔHf°(Fe)] - [2xΔHf°(Al) + ΔHf°(Fe2O3)] = [-1676 + 0] - [0 + (-826)] = -1676 + 826 = -850 kJ。这是铝热反应，大量放热。源自AP Chemistry CED Unit 6生成焓考点。
