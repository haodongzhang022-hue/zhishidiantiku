## 题目
加热25.0g水使其温度从20.0°C升至50.0°C，需要多少热量？（水的比热容 c = 4.18 J/(g·°C)）

## 选项
A. 3.14 kJ
B. 5.23 kJ
C. 6.27 kJ
D. 3.14 x 10^4 J

## 答案
C

## 解析
q = mcΔT = 25.0 x 4.18 x 30.0 = 3135 J = 3.14 kJ。等等重新算：25.0 x 4.18 x 30.0 = 3135 J ≈ 3.14 kJ。所以答案是A。源自AP Chemistry CED Unit 6热容考点。
