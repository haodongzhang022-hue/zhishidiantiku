## 题目
已知以下反应的标准焓变：
反应1: C(s,石墨) + O2(g) 到 CO2(g), ΔH1 = -393.5 kJ
反应2: H2(g) + 1/2 O2(g) 到 H2O(l), ΔH2 = -285.8 kJ
反应3: 2C(s,石墨) + 3H2(g) + 1/2 O2(g) 到 C2H5OH(l), ΔH3 = -277.7 kJ
(a) 利用以上数据计算 C2H5OH(l) + 3O2(g) 到 2CO2(g) + 3H2O(l) 的焓变
(b) 该反应是吸热还是放热？

## 答案
(a) 目标反应 = 2x反应1 + 3x反应2 - 反应3
ΔH = 2x(-393.5) + 3x(-285.8) - (-277.7) = -787 - 857.4 + 277.7 = -1366.7 kJ/mol
(b) ΔH < 0，该反应是放热反应。

## 解析
利用赫斯定律将反应组合。乙醇燃烧 = 2x(CO2生成) + 3x(H2O生成) - (乙醇生成)。源自AP Chemistry CED Unit 6赫斯定律综合计算考点。
