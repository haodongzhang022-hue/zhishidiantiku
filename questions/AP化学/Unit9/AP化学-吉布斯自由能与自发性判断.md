## 题目
某反应在298K时ΔH = -100 kJ, ΔS = -300 J/K。该反应在298K时是否自发？

## 选项
A. 自发，因为ΔH < 0
B. 不自发，因为ΔS < 0
C. 自发，因为ΔG < 0
D. 无法判断

## 答案
C

## 解析
ΔG = ΔH - TΔS = -100 kJ - 298K x (-0.300 kJ/K) = -100 + 89.4 = -10.6 kJ。ΔG < 0，反应自发。虽然熵减小（不利），但焓变足够负使ΔG < 0。源自AP Chemistry CED Unit 9吉布斯自由能考点。
