## 题目
对于一个ΔH < 0 且 ΔS > 0 的反应：

## 选项
A. 任何温度下都自发
B. 任何温度下都不自发
C. 只在高温下自发
D. 只在低温下自发

## 答案
A

## 解析
ΔG = ΔH - TΔS。当ΔH < 0 且 ΔS > 0 时，ΔG始终为负（因为ΔH为负且-TΔS为负），所以任何温度下都自发。源自AP Chemistry CED Unit 9自发条件判断考点。
