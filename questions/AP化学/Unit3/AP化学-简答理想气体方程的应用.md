## 题目
一个5.00L的钢瓶在27°C时含有2.50mol O2气体。
(a) 计算钢瓶内O2的压强。
(b) 如果将温度升高到127°C，钢瓶内气体的压强变为多少？（钢瓶体积不变）

## 答案
(a) 使用PV=nRT：
P = nRT/V = 2.50 x 0.0821 x (27+273)/5.00 = 2.50 x 0.0821 x 300/5.00 = 61.6/5.00 = 12.3 atm

(b) 体积不变时，P1/T1 = P2/T2：
P2 = P1 x T2/T1 = 12.3 x 400/300 = 16.4 atm

## 解析
(a)使用PV=nRT，注意将°C转换为K。(b)使用盖吕萨克定律（恒容条件下P与T成正比）。源自AP Chemistry CED Unit 3理想气体方程应用考点。
