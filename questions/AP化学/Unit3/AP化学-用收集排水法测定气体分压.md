## 题目
在25°C下用排水集气法收集了0.500 L的H₂气体，总压强为755 mmHg。已知25°C时水的饱和蒸气压为23.8 mmHg。请计算收集的H₂的物质的量。

## 答案
H₂的分压 = 总压 - 水蒸气分压
P(H₂) = 755 - 23.8 = 731.2 mmHg

转换为atm：P(H₂) = 731.2 / 760 = 0.962 atm

用PV = nRT：
n = PV/RT = (0.962 atm)(0.500 L) / (0.08206 L·atm/mol·K)(298 K)
n = 0.481 / 24.45
n ≈ 0.0197 mol

即收集到约0.0197 mol H₂。

## 解析
排水集气法收集的气体中包含水蒸气，需要扣除水蒸气的分压。用道尔顿分压定律修正后再用理想气体方程计算。源自AP Chemistry CED Unit 3气体收集与分压考点。
