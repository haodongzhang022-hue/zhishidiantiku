## 题目
中和25.0mL 0.200M NaOH需要多少体积的0.100M HCl？

## 选项
A. 12.5 mL
B. 25.0 mL
C. 50.0 mL
D. 100.0 mL

## 答案
C

## 解析
NaOH与HCl按1:1反应：n(NaOH) = n(HCl)。0.200 x 25.0/1000 = 0.100 x V/1000。V = 0.200 x 25.0/0.100 = 50.0 mL。源自AP Chemistry CED Unit 4酸碱中和计算考点。
